# Komentář k zákonu č. 307/2006 Sb., o evropské družstevní společnosti

Otevřený komentář k zákonu o evropské družstevní společnosti — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; nařízení o statutu SCE, přemístění sídla, založení fúzí, dualistický a monistický systém, zapojení zaměstnanců, vyjednávací výbor a výbor zaměstnanců.

Konsolidované znění: dokument e-Sbírky `SB-2006-00307_2010-07-01`.
